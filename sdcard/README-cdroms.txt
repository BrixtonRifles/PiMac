Put CD-ROM disc images in this folder (.toast, .iso, .cdr, .img).

Supported: plain sector images of a data CD (2048-byte sectors), such as
Toast images and Disk Utility .cdr / .iso images, holding an HFS disc (Mac
CDs, usually with an Apple partition map) or ISO 9660. Audio tracks and
compressed or multi-track images (.bin/.cue, .dmg, .nrg) are not supported.

The emulated drive is an AppleCD 300 at SCSI ID 3, on the Classic, Classic II
and Color Classic. The Mac needs Apple's CD-ROM software in its System Folder:
the Apple CD-ROM extension and Foreign File Access (plus ISO 9660 File Access
for PC/ISO discs). System 7.5's Easy Install includes them.

Insert or eject a disc from the F12 menu (CD-ROM; Left/Right to choose, Enter
to insert or eject). It goes in at once, no restart needed, and stays in the
drive across power cycles until you or the Mac eject it (drag it to the Trash,
or Put Away). Discs are read-only: the image file is never changed.
